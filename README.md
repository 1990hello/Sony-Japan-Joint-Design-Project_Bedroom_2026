# EXORA — Immersive 3D Bedroom Experience (2046)

A photorealistic real-time 3D emotional transition experience.

## Live experience

[Open EXORA](https://1990hello.github.io/Sony-Japan-Joint-Design-Project_Bedroom_2026/)

The site is published with GitHub Pages by the **Deploy to GitHub Pages** workflow whenever changes are pushed to `main`.

## Development

This project uses Bun and Vite.

```bash
bun install --frozen-lockfile
bun run dev
```

To create a production build:

```bash
bun run build
```
